# 用户指南

打字练习（typing）是一个跨平台的五笔打字练习小软件，内置 20 篇现代科技与金融文章，支持导入自己的文章，并提供词组分色、编码提示、跟打练习等功能。

## 安装与启动

### Windows

1. 将 `dist/` 目录整体拷贝到任意位置（该目录含程序与运行库，缺一不可）。
2. 双击 `dist/typing.exe` 即可启动。
3. 无需安装 Qt 或任何依赖。

> 程序为绿色单目录分发：`typing.exe` + 若干 DLL + `platforms/qwindows.dll`。

### macOS / Linux

需要自行编译，见《构建与打包》文档。程序使用 Qt Widgets，三平台界面与功能一致。

## 界面总览

窗口由四个标签页组成：

| 标签页 | 作用 |
| --- | --- |
| 文章库 | 内置 20 篇 + 用户导入的文章列表；双击打开，或点「开始练习」 |
| 阅读 · 提示 | 词组分色阅读；悬停/点击查看五笔编码与拼音；查询框 |
| 练习 | 跟打练习：用系统输入法输入当前字/词，自动前进并统计成绩 |
| 导入文章 | 从 `.txt` 文件导入或粘贴文本 |

窗口顶部还有一个全局开关「显示编码提示（五笔/拼音）」，详见下文。
窗口标题栏与底部状态栏常驻显示**代码版本与编译时间**（如 `v0.2.0 · 编译于 Oct 17 2026 08:53:34`），
便于核对正在使用的版本。

## 阅读文章与编码提示

- **词组分色**：阅读页自动分词，二字词、三字词、四字以上词用不同颜色标出，单字与标点为深色。可勾选「词组分色」开关。
- **悬停提示**：鼠标移到某个字或词上，弹出其**五笔编码与拼音**（字：全码 + 简码；词：词语编码 + 各字拼音）。
- **点击详情**：点击某个字/词，右侧面板显示详细信息——单字（拼音、全码、各级简码、读音）、词语（词语编码、取码规则、逐字拆解表）。
- **查询框**：右上角输入任意单字或词语，回车查询其五笔编码与拼音。

### 关闭编码提示

窗口顶部「显示编码提示（五笔/拼音）」复选框可**手动关闭**全部自动提示：

- 关闭后：阅读页悬停不再弹提示、点击不再显示详情；练习页不再显示拼音与编码行。
- 关闭后查询框仍可用，需要时主动查询即可。
- 开关状态自动保存，下次启动保持上次选择。

## 练习（跟打）

1. 在「文章库」选中文章，点「开始练习」（或切到「练习」页）。
2. 选择练习方式：**单字练习**（逐字）或**词语练习**（按分词逐个词）。
3. 练习页从上到下为：**当前词注音+五笔提示 → 实时统计 → 整齐的原文区**。
4. **注音与五笔编码在界面上方**：当前目标字的拼音与五笔编码固定显示在页面最上方，
   随练习进度自动切换（如 `让 · 注音 ràng · 五笔 YHG`）；可勾选顶部「显示编码提示」随时关闭。
5. **原文在上、输入在下**：当前行原文（已输入部分蓝色、当前目标黄底加粗）在上，
   输入框紧贴其下方、同字号对齐；输入内容在框内逐字累积，与原文逐字匹配。
6. **Word 式排版**：整段按窗口宽度自然折行，行满宽度、左右对齐（不会出现“行尾孤字”
   之类的碎片行），每段首行缩进两字符；窗口缩放后按新宽度自动重排，练习进度原样保留。
7. 用**系统输入法**（拼音、五笔均可）输入：
   - 输入正确则蓝色累积、自动前进；整行完成后自动进入下一行；
   - **跨行词组**：词被折行拆到两行时（如上一行行尾与下一行行首组成的词），
     顶部提示仍显示完整词组，可一次连续输入整词，自动跨越行边界；
   - 输错时自动截断到最长正确前缀并计入错误，继续输入即可；
   - 已完成行以“原文+输入”成对置灰展示在当前行上方，后续行灰蓝待输入。
8. 按钮：`重新开始` 重练本篇，`跳过` 跳到下一行。
9. **窗体上部实时统计**：进度、正确、错误、跳过、用时（时分秒，不含暂停）、**全文速度**与**最近 5 分钟速度**（字/分）；练完显示汇总。
10. **自动暂停**：连续 5 秒没有输入，视为练习暂停，统计栏显示「练习暂停中」，暂停期间不计入用时与速度；重新输入即自动恢复。

> 练习统计的是“打对/打错”，以字为单位（词语练习按词提示，匹配仍逐字进行）。

## 中英双语练习（0.2.0）

练习页顶部左侧下拉框可切换 **「中文练习 / 英文练习」**，两套模式共用同一篇文章：

- **练习中文**：逐字匹配中文原文；右侧面板「英文对照 · 当前中文句」
  高亮显示当前中文句对应的英文译文（当前句黄底加粗、前后句灰色），随进度自动滚动。
- **练习英文**：逐词匹配英文译文（空格跨词、标点一并计入）；右侧面板
  「中文对照 · 当前英文句」高亮当前英文句对应的中文译文；
  **提示区显示当前要输入单词的中英双解含义**（如 `Artificial · 释义 人工的`）；
  进度与速度按字符计。
- 英文模式与中文模式排版一致：**当前行原文在上、输入框紧贴下方**，
  整段按可用宽度折行、不在单词中间断行，已完成行成对置灰，美观整齐；
  **英文行内按词两端对齐**（类似 Word 的 justify）：行内富余宽度均摊到词间空格，
  右缘整齐，仅段落最后一行保持左对齐（0.2.1）。
- 切换语言会重新开始本篇练习（重置进度）；切换文章不影响语言模式。

> 英文练习直接用键盘输入（不依赖中文输入法），字母大小写需与译文一致。

## 导入文章

1. 切到「导入文章」页。
2. 两种方式：点「从文件导入」选择 `.txt`；或在文本框粘贴内容后点「保存到文章库」。
3. 导入成功后文章出现在「文章库」（标记为 `[导入]`），可正常阅读与练习。
4. 导入文章会持久化保存，重启后仍在；在导入页可删除自己导入的文章（内置文章不可删）。

> 建议：纯文本、UTF-8 编码；标题取文件首行（若有），正文不要求分段。每篇 500–5000 字为宜。

## 数据规模

- 单字五笔码表：20,901 字（含全码与各级简码）
- 词语表：62,787 词（码表全部 2–6 字词 + 248 个现代科技/金融补充词）
- 拼音：26,712 字
- 英文译文：20 篇内置文章逐句中英对照 806 句；英文单词释义 4,023 词
- 内置文章：20 篇（科技 10 + 金融 10），每篇约 1,800–1,880 字，合计 36,476 字

## 常见问题（FAQ）

**Q：双击 exe 报“缺少 DLL”或无法启动？**
A：`dist/` 目录必须整体拷贝（含 Qt6*.dll、libgcc_s_seh-1.dll 等与 `platforms/` 子目录），不能只拷 exe。

**Q：练习时输入框打不出汉字？**
A：确认系统已安装并切换出中文输入法（微软拼音/搜狗/五笔等）；练习输入框使用系统 IME，输入法状态为中文即可。若输入一两个字后输入区不再接收新字符，请升级到 0.1.9+（该问题已修复）；仍异常可尝试 `重新开始` 或重启程序。

**Q：练习英文时打不了字？**
A：英文练习直接用键盘输入即可，无需中文输入法；请确认输入框已获得焦点（点击输入框）。字母大小写需与译文一致，输错会自动截断到最长正确前缀。

**Q：为什么有些词语没有被颜色标出？**
A：分词依赖内置词表。若词表确实没有该词（生僻词/新词），会按单字处理。可通过导入文文章 + 阅读页查询框确认；如需扩充词表，见《数据与编码》。

**Q：导入的文章保存在哪里？**
A：按平台用户数据目录保存（Windows 为 `%APPDATA%/typing/typing/wubi_practice_articles.json`）。

**Q：提示关掉了怎么再开？**
A：勾选窗口顶部「显示编码提示（五笔/拼音）」即可，状态自动保存。

## 卸载

绿色软件：删除 `dist/` 目录即可；如需清除导入文章与设置，删除上述用户数据目录下的 `wubi_practice_articles.json` 与注册表中 `HKEY_CURRENT_USER\Software\typing\typing`（Windows）。
