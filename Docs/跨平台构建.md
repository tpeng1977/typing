# 跨平台构建指南

本项目基于 C++17 + Qt6 Widgets + CMake，支持 **Windows / Linux / macOS** 三平台直接编译。

## 依赖

- CMake ≥ 3.16
- C++17 编译器（Windows: MinGW 11+ / MSVC 2019+；Linux: GCC 9+；macOS: Clang 12+）
- Qt6 Widgets 模块（6.2+）

## Windows

```bash
# 环境：Qt 6.5.x + MinGW 11.2.0 64bit + CMake + Ninja
mkdir build && cd build
cmake .. -G Ninja -DCMAKE_PREFIX_PATH=C:/Qt/6.5.3/mingw_64
cmake --build .
```

## Linux

```bash
# Ubuntu / Debian 安装依赖
sudo apt install build-essential cmake qt6-base-dev

# 编译
mkdir build && cd build
cmake ..
cmake --build . -j$(nproc)
```

## macOS

```bash
# 用 Homebrew 安装 Qt6
brew install qt@6

# 编译（Qt6 路径需手动指定）
mkdir build && cd build
cmake .. -DCMAKE_PREFIX_PATH=/opt/homebrew/opt/qt@6
cmake --build .
```

## 运行

编译完成后直接运行：

```bash
# Windows
build\typing.exe

# Linux / macOS
./build/typing
```

## 命令行测试

```bash
./typing --selftest   # 数据完整性自检
./typing --ime-test   # 输入法链路测试
./typing --en-test    # 英文练习链路测试
```

## 说明

- 所有数据文件（文章、码表、拼音、中英对照）通过 Qt 资源系统（qrc）编译进可执行文件，无需额外数据文件。
- 图标使用 PNG 格式（`res/app_icon.png`），三平台通用；`.ico` 仅 Windows 备用。
- 源码无任何平台特定 API（无 `_WIN32` / `__APPLE__` / `Q_OS_*` 条件编译）。
