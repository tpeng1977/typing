# 开发指南

本指南面向想阅读、修改或扩展 typing 源码的开发者。项目使用 **C++17 + Qt Widgets + CMake**，跨 Windows / macOS / Linux。

## 模块职责

### dataloader（Dict 单例）

- 启动时通过 Qt 资源系统加载三张表（`:/data/wubi_char.txt`、`:/data/pinyin.txt`、`:/data/words.txt`）。
- 对外接口：
  - `wubiFull(c)` 单字全码；`wubiBriefs(c)` 各级简码；`allWubi(c)` 全部码。
  - `pinyin(c)` / `pinyins(c)` 读音。
  - `hasWord(w)` 判断词表是否收录；`wordCode(w)` 词语编码——优先查表，查不到时用 `computeWordCode` 按五笔取码规则回退计算（因此任何 2–6 字词都能给出编码）。
- 取码规则（与《数据与编码》一致）：
  - 二字词：第 1 字前 2 码 + 第 2 字前 2 码；
  - 三字词：第 1 字首码 + 第 2 字首码 + 第 3 字前 2 码；
  - 四字及以上：前 3 字首码 + 末字首码。

### segmentation

- 纯正向最大匹配：从当前位置尝试最长 6 字词，命中即切；否则按单字。
- 返回 `QVector<Token>`，`Token{start, len, isWord}`。
- 阅读页与练习页共用同一分词结果，保证展示一致。

### article（ArticleStore）

- 内置文章编译期嵌入（`articles.json`）；导入文章持久化到 `QStandardPaths::AppDataLocation` 下的 `wubi_practice_articles.json`。
- 区分 `builtin` 与 `imported`；导入文章可删，内置不可删。

### reader（ReaderView + ReaderBrowser）

- `ReaderBrowser` 开启鼠标追踪，通过 `anchorAt` 命中 `tok:<idx>` 锚点，发出 `tokenHovered` / `tokenActivated`。
- 词组分色配色：单字 `#333a45`、二字词 `#1d4ed8`、三字词 `#0f766e`、四字+ `#7c3aed`。
- 悬停 tooltip 与点击右侧详情；查询框 `lookup_` 走 `charDetailHtml / wordDetailHtml / lookupResultHtml`。
- **提示开关**：`setHintsEnabled(bool)`；关闭时 `onHovered` 清空 tooltip、`onActivated` 直接返回，查询框不受影响。

### practice（PracticeView，按模块拆分于 practice.cpp / practice_lines.cpp / practice_match.cpp / practice_render.cpp）

- 跟打模式：输入框接收**系统输入法**提交的汉字（`textEdited` 信号），与目标 `targetText()` 比对。
- 判错逻辑：完全匹配 → 正确并前进；是目标前缀（词语输入中）→ 继续等待；其余 → 计错并截断。
- 匹配核心（`practice_match.cpp`）：输入框与“当前行行首到文末的连续正文”做前缀匹配，
  支持跨行词组整词输入与单行内逐字输入（0.1.9 起匹配起点 = 行首 `lineStarts_[lineIdx_]`）。
- 折行（`practice_lines.cpp`）：中文按字符逐字折行、每段首行缩进两字符；
  英文按词折行（不在词中间断行）。
- 渲染（`practice_render.cpp`）：行标签统一使用 `JustifiedLabel` 自绘——
  **英文行两端对齐**（词间空格均摊富余宽度，最后一行左对齐），当前行按
  已输入蓝 / 目标黄底加粗 / 其余黑分段着色；右侧句子对照与统计栏同步刷新。
- **提示开关**：`setHintsEnabled(bool)`；关闭时目标大字不附拼音、编码提示行清空。
- 统计：正确/错误/跳过/用时/速度；`finished_` 后显示汇总并禁用输入。

### mainwindow

- 四标签页；顶部「显示编码提示」全局开关 `hintChk_`，状态经 `QSettings` 持久化（`hintsEnabled`），联动 `reader_` 与 `practice_`。

## 扩展指南

### 新增内置文章

1. 在 `articles/` 增加 `artNN.txt`（首行标题，其余为正文）。
2. 运行 `python _data/build_data.py` 重新生成 `res/articles.json`。
3. 重新编译（数据经 Qt 资源系统嵌入二进制）。

### 扩充词语表 / 修复分词

- 词表来源：`_data/build_data.py` 解析 `wubi86_jidian.dict.yaml`（**完整收录全部 2–6 字词，禁止再加固定条数截断**）。
- 现代科技/金融补充词：编辑 `_data/extra_words.txt`（每行一个词），重新运行生成脚本即可；编码按取码规则自动计算。
- 生成后建议在 `src/selftest.cpp` 的 `runSelfTest()` 中追加回归断言（见《测试与质量》）。

### 修改界面文案 / 配色

- 文案集中在各 `.cpp` 的 `QStringLiteral(...)` 中；词组分色配色在 `reader.cpp` 顶部常量。

### 修改提示开关行为

- 开关状态流：`MainWindow::hintChk_` → `ReaderView::setHintsEnabled` / `PracticeView::setHintsEnabled`。新页面若也有提示，按同样模式接入。

## 编码约定

- 语言：C++17；Qt 风格命名（类 `PascalCase`，成员 `camelCase_` 尾下划线）。
- 界面文字统一简体中文，经 `QStringLiteral`。
- 数据加载失败要有回退/报错，不静默（`Dict::ok()`、自检 FAIL 路径）。
- 源码/构建目录**必须是纯 ASCII 路径**：MinGW + CMake AUTOMOC 无法解析含中文的相对路径（历史踩坑，勿回归）。
- 依赖 Qt 资源系统：新增资源文件须在 `resources.qrc` 登记；不要改用 `qt6_add_resources()`（本环境不生成 rcc 对象，用 `AUTORCC` + 源列表列 qrc）。
