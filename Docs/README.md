# typing 文档

本目录是打字练习的完整文档。按角色选择入口：

| 文档 | 读者 | 内容 |
| --- | --- | --- |
| [用户指南](用户指南.md) | 使用软件的人 | 安装、启动、功能使用、常见问题 |
| [开发指南](开发指南.md) | 想改代码的人 | 架构、模块职责、扩展方法、编码约定 |
| [数据与编码](数据与编码.md) | 想理解/重建数据的人 | 数据来源、文件格式、生成流程、五笔取码规则 |
| [构建与打包](构建与打包.md) | 要在各平台编译/分发的人 | Makefile 目标、三平台构建、打包部署 |
| [测试与质量](测试与质量.md) | 维护者 | `--selftest` 自检、回归检查、历次验证记录 |
| [更新日志](更新日志.md) | 所有人 | 版本演进与修复记录 |

根目录 `README.md` 是项目总入口（快速开始 + 功能概览），本目录提供深入细节。

## 快速导航

- 只想用：看 [用户指南](用户指南.md)，或直接双击 `dist/typing.exe`。
- 想编译：看 [构建与打包](构建与打包.md)。
- 想加文章：看 [用户指南](用户指南.md)（界面导入）或 [开发指南](开发指南.md)（内置文章）。
- 想改词库/数据：看 [数据与编码](数据与编码.md)。
