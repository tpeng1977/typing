# 打字练习（typing）

一个跨平台的**打字练习小软件**（支持中文五笔/拼音跟打与英文练习），使用 **C++17 / Qt Widgets** 开发，同一份代码可在
**Windows、macOS、Linux** 上编译运行。内置 20 篇现代科技与金融练习文章，支持导入自己的文章。

## 功能特性

- **20 篇内置练习文章**：现代科技 10 篇 + 金融 10 篇，每篇约 1,800–1,880 字。
- **文章库**：内置 + 用户导入（`.txt` / 粘贴），导入内容持久化保存，重启不丢。
- **词组分色显示**：自动分词，二字 / 三字 / 四字以上词用不同颜色标出，可开关。
- **字 / 词提示**：悬停查看五笔编码与拼音；点击查看详情（全码、简码、读音、词语取码规则、逐字拆解）；另有查询框。
- **提示开关**：窗口顶部「显示编码提示」可**手动关闭**全部自动提示（悬停/点击/练习提示），设置自动保存。
- **跟打练习**：**当前词注音+五笔编码固定显示在界面上方**，随练习自动切换；
  **原文在上、输入在下**——当前行原文与输入框同字号对齐、输入内容逐字累积匹配，
  整行完成自动进入下一行，已完成行“原文+输入”成对置灰展示；
  **Word 式排版**：同一段按窗口宽度自然折行、左右对齐（行满宽、不出现碎片行），
  每段首行缩进两字符，窗口缩放后自动按新宽度重排并保留练习进度；
  **跨行词组**：词被折行拆到两行时提示仍显示完整词组，可一次性连续输入、自动跨行前进；
  窗体上部实时统计正确 / 错误 / 跳过 / 用时（时分秒），并显示**全文速度**与**最近 5 分钟速度**；
  连续 5 秒无输入自动暂停，暂停期间不计时、不计速度。
  **0.1.9 修复**：真实输入法逐字输入时不再出现“输入一两个字后输入区不接收新字符”
  （匹配起点与输入框行首累积语义对齐；跨行词组整词输入能力保持不变）。
- **中英双语练习（0.2.0）**：20 篇内置文章均配有逐句英文译文（806 句中英对照），
  顶部下拉可切换**中文练习 / 英文练习**；练习中文时右侧高亮显示当前中文句对应的英文译文，
  练习英文时右侧高亮当前英文句对应的中文译文；提示区同步显示当前字词的
  **中英双解含义**；英文练习同样采用「原文在上、输入在下」的逐行排版，
  且行内按词**两端对齐**（类似 Word 的 justify，最后一行左对齐；0.2.1）。
- **版本信息显示（0.2.0）**：窗口标题栏与状态栏常驻显示**代码版本与编译时间**
  （如 `v0.2.0 · 编译于 Oct 17 2026 09:29:04`）。
- **数据规模**：单字五笔码表 20,901 字、词语 62,787 词、拼音 26,712 字、
  英文译文 806 句 + 英文单词释义 4,023 词，全部嵌入单个可执行文件。
- **源码组织（0.2.1）**：`practice.cpp` 与 `main.cpp` 按功能模块拆分为
  多个小文件（`practice_lines/match/render`、`selftest/imetest/entest`），
  便于阅读与跟踪，逻辑零改动。

## 快速开始

### 直接运行（Windows）

`dist/` 是绿色分发目录：把整个目录拷贝到任意位置，双击 `dist/typing.exe` 即可，无需安装 Qt。
> 必须整目录拷贝（exe + DLL + `platforms/` 子目录）。

### 从源码构建

需要 **CMake ≥ 3.16** 与 **Qt 6.5+（Widgets）**，三平台通用：

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH=<Qt安装路径> -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

也提供 `Makefile` 包装（`make` / `make run` / `make selftest` / `make dist` / `make clean`），
各平台参数示例见 [Docs/构建与打包.md](Docs/构建与打包.md)。

### 自检

```bash
typing --selftest     # 退出码 0 表示数据与逻辑全部通过
```

## 使用说明

- 阅读：文章库双击文章 → 词组分色阅读；悬停/点击查看编码，查询框主动查询。
- 练习：选中文章点「开始练习」→ 用系统输入法输入当前字/词，自动前进；
  顶部下拉切换中文/英文练习，右侧为另一语言对照。
- 导入：`导入文章` 页从文件导入或粘贴文本。
- 详细操作与 FAQ 见 [Docs/用户指南.md](Docs/用户指南.md)。


## 数据来源

- 单字/词语五笔码表：开源 Rime 方案 `KyleBing/rime-wubi86-jidian`（86 版王码五笔）。
- 拼音数据：`mozillazg/pinyin-data`。
- 20 篇练习文章：本项目原创编写。

数据在编译期经 Qt 资源系统嵌入二进制，**单个可执行文件即可分发**。
重新生成数据的方法见 [Docs/数据与编码.md](Docs/数据与编码.md)。
